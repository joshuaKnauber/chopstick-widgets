# Chopstick widgets

Widgets people made for [Chopstick](https://chopstick.sh), the Mac app that puts
widgets on the notch. Browse and install them at
**[chopstick.sh/widgets](https://chopstick.sh/widgets)**.

Each folder in [`widgets/`](widgets) is one widget, exactly as Chopstick
imports it: a `widget.json` and the scripts it runs. Once a widget is merged
here, it gets its own page on the site with an install button.

Made a widget you'd like to share? See [CONTRIBUTING.md](CONTRIBUTING.md).
